# agents_driven_sdlc

Два общих скила Codex для проектирования архитектуры и управляемой реализации:

* `design-project-architecture`
* `plan-implement-review`

## Установка на этом Mac

```bash
./scripts/install.sh
```

Скрипт создает пользовательские симлинки в `~/.agents/skills`. Codex поддерживает эту директорию и следует по симлинкам. Поэтому изменения в этом репозитории становятся доступны без копирования файлов. Повторный запуск обновляет существующие симлинки.

Если Codex не показывает изменения автоматически, перезапусти приложение.

Для другого пользовательского каталога передай `AGENTS_SKILLS_DIR`:

```bash
AGENTS_SKILLS_DIR=/path/to/skills ./scripts/install.sh
```

Скрипт не перезаписывает обычный файл или каталог с совпадающим именем.
